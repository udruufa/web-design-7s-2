## Полезные промпты

> «Необходимо создать дашборд "Everydaying" из 6 виджетов:
обычные:
- список дел
- календарь событий
- заметки

с подключение API:
- запрос рандомного слова с его значением - https://randomlexicon.com/api-reference
- рандомный факт - https://uselessfacts.jsph.pl/
- рандомная вопрос викторины - https://opentdb.com/api_config.php

Обязательный функционал:

- Добавление, сворачивание и удаление виджета; ошибка одной карточки не ломает остальные.
- В списке дел работают добавление, отметка выполнения и удаление.
- В календаре работают добавление и удаление события.
- Сетевые карточки показывают загрузку, результат либо ошибку с кнопкой повтора.
- После обновления страницы восстанавливаются виджеты и задачи.
- Панель удобно выглядит на телефоне и компьютере.

Обязательно:
- При выключенном интернете у API должна появиться ошибка и возможность повтора.».

Метод destroy() удаляет карточку и освобождает её обработчики/таймеры.
Используй export. Встрой класс в существующие файлы, сохрани дизайн.
Выдай полный код изменённых файлов, без пропусков.».

> «Создай класс Dashboard для нашей панели. addWidget(type) создаёт виджет нужного типа и добавляет на страницу, removeWidget(id) вызывает destroy и удаляет его из коллекции. Запрети повторное добавление одного типа, покажи понятную подсказку. Подключи кнопки в main.js и импорты модулей.
Выдай полный рабочий код изменённых файлов.».
